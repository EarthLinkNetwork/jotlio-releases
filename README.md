# Jotlio for Mac — releases

The DMG downloads and the signed Sparkle update feed (`appcast.xml`) of Jotlio for Mac. Installed
copies read `releases/latest/download/appcast.xml` and update themselves.

Homebrew: `brew install --cask earthlinknetwork/tap/jotlio` (cask in EarthLinkNetwork/homebrew-tap).

Releases here are published only by Jotlio's release workflow. Do not publish anything else in this
repository: `releases/latest` must always be a Jotlio release.
